# Basic-Cybersecurity-Policy
create a basic cybersecurity policy for a small organization.

 Description

This project focuses on creating a basic cybersecurity policy for a small organization. 
It explains essential security rules that help protect organizational information, devices, accounts, and systems.

Objective

To understand organizational security controls and the importance of cybersecurity policies.

Topics Covered

- Password and Account Security
- Device and Data Security
- Email and Internet Security
- Access Control and Confidentiality
- Incident Reporting and Response
- Data Backups and Safe Handling
- Security Awareness and Compliance

Key Learning

I learned how cybersecurity policies establish clear security rules, reduce risks, protect sensitive information, 
and guide employees in reporting security incidents.

Interview Questions

1. What is a security policy?

2. Why are policies important?
   

Conclusion

This task helped me understand the importance of cybersecurity policies in protecting an organization’s data, devices, and systems. 
I learned how password security, safe email practices, access control, and incident reporting help reduce cybersecurity risks and create a safer working environment.
